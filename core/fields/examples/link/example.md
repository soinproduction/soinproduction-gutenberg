# Link / Action

Метод: `addLink`. Тип в схеме: `link`.

## Объявление в schema.ts

```ts
import { fields } from '@kit/core/fields/schema';

export const schema = fields()
  .addLink('cta', {
    label: 'Call to action',
    instructions: 'Choose a page, service, post, modal or custom URL.',
    defaultValue: {
      text: '',
      url: '',
      modalId: 0,
      icon: '',
      iconPosition: 'after',
      plan: '',
    },
  })
  .build();
```

## Опции этого поля

| Опция | Тип | По умолчанию | Поведение |
| --- | --- | --- | --- |
| `label` | string | Производная от имени поля в редакторе; для toggle на фронте — имя поля. | Заголовок панели действия. |
| `instructions` | string | Не задано | Подсказка в панели InspectorControls; во вложенном контроле отдельно не выводится. |
| `defaultValue` | Зависит от типа | См. формат значения | Начальное значение указанного выше формата; не перезаписывает явно сохранённое значение. |

Другие ключи общего `FieldOptions`: `placeholder`, `choices`, `min`, `max`, `step`, `postType`, `tag`. Для этого поля они не подключены к контролу/выводу. Общий TypeScript-тип пока принимает их, но это не означает поддержку. Полная матрица — в [каталоге примеров](../README.md#опции).

## Значение

объект действия; без defaultValue — `{ text: '', url: '' }`. Остальные свойства необязательны.

`defaultValue` в примере демонстрирует API. Его можно убрать; реальные данные вводятся в админке. Не вставляй ID, URL и контент чужого сайта как defaults.

## Вывод в component.tsx

```tsx
import { Field } from '@kit/core/fields/render';

<Field name="cta" className="inline-flex gap-2" />
```

Фрагмент используется внутри компонента модуля под `FieldScope`; его подключают SchemaEditor в editor.tsx и общий defineModule. Пропсы JSX не являются опциями schema.ts. Полный список props и отдельные функции рендера — [в каталоге](../README.md#рендер).

## Свойства сохранённого действия

Это свойства значения, а не дополнительные schema-опции.

| Свойство | Тип / значения | Назначение |
| --- | --- | --- |
| `text` | string | Текст кнопки. |
| `url` | string | Обычная ссылка: `/contacts`, `#gallery`, `https://…`, `mailto:…`, `tel:…`. |
| `modalId` | number, 0 если обычная ссылка | ID опубликованной модалки; имеет приоритет над URL. Рендерится актуальный `/#modal-slug`. |
| `icon` | string, пустая строка без иконки | Ключ из библиотеки иконок проекта. |
| `iconPosition` | `'before'` / `'after'` | Положение иконки; по умолчанию after. |
| `plan` | string | Необязательный ключ тарифа для booking-модалки; передаётся как `data-modal-plan`. |

Модалка должна присутствовать в `site.modals`; удалённая/неопубликованная модалка не даёт активной кнопки. Обычные ссылки проходят фильтрацию URL.

## Особенности и ограничения

Базовый рендер использует компонент Action и класс `wp-block-button__link`. Для стилей кнопки проекта помести Field внутрь контейнера `site-actions`. Кнопка без текста или допустимого назначения не выводится. `target`, `rel`, `variant`, `return_format` и автоматическая связь с изменением slug выбранной страницы/услуги/статьи пока не поддерживаются: обычная ссылка сохраняется строкой URL. Модалка сохраняется ID и разрешается в актуальный slug при рендере.
