Паттерн компонентов Kit

Для обычного поля используйте kit(kind, describeField, render). Для составного компонента опишите field рядом с разметкой и используйте useClasses для объединения трёх вариантов классов.

  • name — ключ сохранённых данных, label — подпись в редакторе.
  • className применяется везде, adminClassName добавляется в Gutenberg, frontClassName добавляется на сайте.
  • useField(name) даёт значение и setValue. useValues() читает соседние поля, useSite() — общие данные сайта.
  • List собирает схему строки из детей. Records выбирает записи и передаёт контекст дочерним Record*.
<Buttons
  name="actions"
  label="Действия"
  className="flex gap-4"
  adminClassName="outline"
  frontClassName="mt-preset-40"
/>
